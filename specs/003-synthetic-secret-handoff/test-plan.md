# Acceptance matrix and evidence plan

Source is the CEO-accepted COU-6 matrix and decision named in [the specification](spec.md). U is the authenticated local operator, A the enrolled participant, R the actual managed run, and G the enrolled generation. Execute the matrix in one disposable local project on the declared native Windows ARM64 package. Use a controlled clock and independent counters for adapter invocation, fake effect and render. All variants use distinct IDs and internally generated canaries. Counters reset per case, with same-ID continuity retained within retries.

Contract keys below are [Authority](contracts/authority.md), [Effects](contracts/requests-and-effects.md), [UI](contracts/operator-ui.md) and [Custody](data-model.md). Each row needs executed evidence, with the expected assertions below and any platform gaps explicitly flagged.

## Leakage coverage

- Generate independent unpredictable canaries (at least 128 bits of entropy) inside the broker with a fixed ASCII representation. The broker compares internally or seeds only the authorized fake and renderer through the private test channels. The detector runs inside the trusted fixture boundary, uses in-memory forbidden variants, and emits path categories, coverage, counts and outcome only. Never write a canary, capture excerpt, deterministic hash, variant or extractor payload to an artifact. Run isolated positive controls for exact, encoded and screenshot/text-capable checks separately from the evidence of zero leakage. Partial strings in transformed error paths are checked using several disjoint canary substrings with unrelated-baseline controls.
- Check exact raw bytes and UTF-8/UTF-16LE/BE, common escaping and transformations from the actual tooling (JSON/Unicode escapes, URL encoding, hex, Base64 and Base64url), decoding serialized or compressed artifacts inside the trusted verifier as needed. Failure to inspect an applicable format leaves the gate incomplete. Include malformed/error/timeout inputs, rejected response echoes, and content crafted by the fake to test dropped fields. Counters never derive from caller success text.
- Inspect model/tool message wiring, chat/fixture transcript, CLI/MCP including JSON and error envelopes, Herdr terminal transcript/PTY/screen captures and exports, Workspace and execution result captures, Council artifacts, and outbound Plane payload observation. Pilot emits no Plane event, uses no live provider, and injects none of these bytes into any model. When a connector is absent and no payload can exist, verify isolation and zero outbound attempts with the fixture interceptor. A deterministic Node/native fixture or simulated model boundary must be reported as such.
- Inspect every pilot process and child argv, actual inherited environment, stdout/stderr, app/core/OS pilot event logs, tracing/telemetry sinks, crash/dump settings and crash survivors, pilot scratch, protected store files including database/WAL for plaintext, and related workspace/Git untracked, staged and tracked content and pilot commits. Verify writable paths and telemetry/egress for the fixture. Exclude unrelated personal data from collection. Store artifacts never carry plaintext. Do not create a dump of secret-bearing memory.
- From the participant or same-user decoy attempt to observe protected UI via ordinary accessibility, native capture and clipboard surfaces and to inject into the operator session. Verify no copy action, no leak in accessible metadata or screen sharing, no value-bearing screenshot; retain only probe booleans or counters. Verify the selected native control paints once using a comparator inside that surface. No video or screenshot of the live reveal is retained. Document protected-process and desktop prerequisites and mark any unobservable required surface incomplete.

## Evidence to publish

Use one redacted report per package/build with package digest, exact commit, OS build and ARM64 mode, Desktop/core/Council versions, provisioned security properties or failed preconditions, participant type and execution layers. Per case, include sequence of safe event names and opaque IDs, crash cut and disposition, independent invocation/effect/reveal deltas, reconciliation reference and leakage coverage/positive-control results. Include keyboard and safe accessibility inspection. Redacted supporting artifacts may include UI screenshots only with no value rendered. Log all skipped or blocked assertions clearly.

Record pure unit/fault simulations separately from live local Herdr with a deterministic fixture and from actual native OS controls. An ordinary repo suite pass only shows regressions for its exercised scope. A real harness, other platform, power-loss guarantee and real-value release each need distinct verification before any such claim. No real model or credential is required by this pilot.
