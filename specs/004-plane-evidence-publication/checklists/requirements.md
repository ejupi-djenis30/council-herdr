# Specification quality checklist

- [x] Three independently testable stories and measurable outcomes.
- [x] Instance, workspace, project, item and local installation identities, including homonyms.
- [x] Exact authorized destination and payload, typed Council status and provider URL verification.
- [x] Local lifecycle and Plane planning-field ownership, explicit operator authority and integration key custody.
- [x] Offline behavior, conflicts, durable sender fence, positive-only receipt and bounded recovery.
- [x] Baseline compatibility, contracts, phased file ownership, regression vectors and quickstart.
- [x] Real read observations distinguished from fixture evidence and still-required installed/live gates.
- [x] No creation, planning field mutation or synthetic-vault dependency in the feature contract.
