# Specification quality checklist

- [x] Stories have independent tests and measurable cross-surface outcomes.
- [x] The accepted roadmap, existing records, migration, and mixed-writer behavior are covered.
- [x] Triage, explicit acceptance, exact evidence, rework, and reopen have normative contracts.
- [x] Formal disputes retain their verdict and the existing authorization boundary.
- [x] All requirements map to named regression or integration gates, with clear evidence categories.
- [x] Backend, frontend, and integration responsibilities are assigned. COU-9 follows COU-8 and COU-6 is separate.
- [x] Scope assumptions are explicit and no clarification markers remain.
